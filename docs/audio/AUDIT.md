# 사운드 감사

> Claude는 소리를 들을 수 없다. 이 문서는 **도구로 잴 수 있는 것**(길이·피크·RMS·스펙트럼·컴프레서 눌림·재생 빈도·보이스 스틸)만 숫자로 적고, 좋고 나쁨은 판단하지 않는다. 귀로 확인할 것은 `?soundlab=1` Sound Lab에서 듣고 메모(`hodl.soundNotes`)로 남긴다.

## 다시 만드는 법

```sh
node tools/audio/audit.cjs     # 효과음 전체 + 옵션 변형 + BGM 렌더/측정 → docs/audio/data/{sfx,bgm}.json
node tools/audio/freq.cjs      # 봇 판 N개를 가상 시계로 돌려 Sound.play 호출 수집 → docs/audio/data/freq.json
node tools/audio/report.cjs    # 이 문서의 표(TABLES 구간)를 다시 씀 — 구간 밖 글은 보존
```

측정은 `OfflineAudioContext`(44.1kHz 모노)에서 실제 `audio.js`·`music.js` 코드를 그대로 렌더한 값이다. 컴프레서 눌림은 "압축 없이"(ratio 1) 렌더와 게임 설정 렌더의 RMS 비로 구했다.

### 덤으로 나온 것

- ⑧ **저음 쏠림**: 이 게임의 소리는 스펙트럼 중심이 낮은 쪽에 몰려 있다 (표 '효과음 전체').
- ⑨ **BGM이 저음 위주**: 채널별 균형 표 참고.
- ⑩ **BGM ↔ 효과음 음량차**: market 곡 RMS가 −22.8 ~ −23.1 dBFS로 mood와 무관하게 거의 같다. 효과음 평균과의 차는 표 참고.
- ⑪ **병합 창(30ms)이 사다리 음을 먹는다**: 콤보·정산이 한 틱에 몰리면 높은 단계 음이 병합으로 사라진다. 봇의 `cardPlay`·`shopShuffle`은 사람보다 빠르게 눌러 생기는 인공물이라 표에서 따로 표시.
- ⑫ **루프 이음새 문제 없음**: 곡 끝→처음 점프가 다른 마디 경계 점프를 넘지 않는다.
- ⑬ **컴프레서 메이크업 +9.3dB**: 임계값 아래의 작은 소리도 일률적으로 +9.3dB 올라간다 (정적 곡선 표). 그래서 "작게 만든 소리"가 실제로는 작지 않을 수 있다.

## 귀로 확인할 목록 (Sound Lab)

1. 음량 격차 표의 ±6dB 이탈 22개 — 거슬림/약함 메모.
2. 고음 비율 60% 이상 + 자주 나는 소리 — 피로감.
3. 장면 `정산 연쇄`·`콤보 사다리`·`장 마감 직전`·`반대매매 위기` — 겹칠 때 어느 소리가 묻히는지.
4. 팩 개봉 등급별 — 신화가 일반과 확실히 다른지.
5. BGM 곡·레이어 토글 — 큰 효과음 뒤 BGM이 눌렸다 올라오는 느낌.
6. 사다리 12단 — 위쪽 단계가 날카로운지.

## 한계

- 빈도는 **봇**이 친 판이다(전략 3종 이상, 8판). 사람은 더 느리고 불규칙하다.
- BGM은 꺼진 상태로 쟀다(빈도 측정). 온보딩은 전부 연 상태, 연출 스킵 없음(설정 '보통').
- 오프라인 렌더는 44.1kHz 모노 — 스테레오·실제 하드웨어 응답은 반영하지 않는다.
- 이번 8판에서 `bankrupt`는 한 번도 안 울렸다 (스틸 판정 불가).
