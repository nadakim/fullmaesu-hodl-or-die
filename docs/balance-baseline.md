## 눈에 띄는 점 (현재 버전)

- **파산이 한 번도 없다** — 모든 전략·모든 찌라시 모드에서 파산율 0%. 반대매매는 판당 0.2~0.6회 일어나지만 순자산이 0 아래로 가지 않는다. 게임오버는 전부 목표 미달(대부분 NEAR_MISS·SLOW_BLEED).
- **카드를 많이 쓸수록 불리하다** — allCards·shopper가 stocksOnly보다 1주 통과율·생존 주 수가 낮거나 비슷하다. 카드 전부 사용 = 공매도·헤지·손절 카드도 무작정 쓰는 봇이라 전략 품질의 하한선에 가깝다.
- **암시장 구매가 손해** — shopper(매주 1개 구매)가 allCards보다 8주 클리어율·평균 순자산이 낮다. 구매 비용이 순자산(목표 판정)에서 바로 빠지기 때문.
- **아무것도 안 해도 가끔 통과** — nothing이 찌라시 A 고정일 때 1주 통과 15.5%, 8주 클리어 1.8%. 찌라시의 현금·매수 효과만으로 목표를 넘는 판이 있다 (예: 시드 28, 찌라시 22회로 최종 ₩ 85,704만).
- **yolo 봇은 대부분 신용 매수(2x)로 산다** — 영끌은 시작 덱에 없는 전설 카드(희귀도 가중치 10)라 보상에 드물게 뜬다. 그래도 stocksOnly(1x)보다 약간 낫다 (찌라시 무작위 기준 8주 클리어 10.3% vs 7.8%).

### 막히는 지점

**① 1주차: "nothing ≤ 10%"와 "stocksOnly 85% 이상"은 같은 목표치로 동시에 못 맞춘다.**
nothing의 1주 순자산은 찌라시 도박 결과만큼 흔들린다 (중앙값 10,020 · 상위 10% 10,725). nothing을 10% 이하로 떨어뜨리려면 1주 목표가 10,800 이상이어야 하고, 그러면 stocksOnly는 **1주 만에 +8% 이상 벌어야** 통과한다. stocksOnly의 1주 결과는 지수 흔들림(× 종목 beta)이 좌우한다:

| 실험 (드리프트 0, 탈락 없음) | stocksOnly 1주 하위 12.5% |
|---|---:|
| 현재 | 8,898 |
| 종목 고유 변동 절반 (`IDIO_SCALE` ½) | 8,903 |
| 지수 전달 끔 (`IDX_SENS` 0) | 9,467 |

드리프트로 밀어 올리면 1주 목표 10,800 기준 stocksOnly 통과가 0.001 → 0.002 → 0.003에서 46 → 57 → 67%, **0.005에서야 87.5%**(nothing 9.8%)가 된다. 그런데 0.005면 사서 1주 들고 있을 때 이길 확률이 반도체전자 99%·국밥제약 100%·지수 인버스 100%이고 stocksOnly 8주 중앙값이 17.7만(시작의 17배)이다 — "약간 플러스"가 아니라 "사면 무조건 번다". 찌라시 금액 폭을 줄여 nothing 상위 10%를 10,200까지 내려도 stocksOnly 상한은 약 61%다.
→ "약간 플러스"를 지키면서 1주차 통과율을 85%로 올리려면 **1주차 변동성 자체**(지수 전달 `IDX_SENS`, 시장 이벤트 BULL/BEAR 크기, 시작 덱의 고베타 종목 비중)를 건드려야 한다.

### 고정 금액 vs "지난 주 대비 +N%"

고정 금액을 유지했다. 1주차는 두 방식이 같다(둘 다 시작 자금 대비). 탈락 없이 돌린 데이터(변경 후 규칙)에서 주간 순자산 증가율 중앙값은 2~3주차에 nothing ×1.02~1.04 / stocksOnly ×1.12~1.13으로 갈리지만, 5주차 이후엔 nothing도 ×1.11~1.15(찌라시로 산 종목이 드리프트를 탄다)로 stocksOnly(×1.12~1.15)와 비슷해져 후반에는 "+N%" 목표가 두 봇을 가르지 못한다. 또 크게 번 주의 여유분이 다음 주로 이월되지 않아 잘한 플레이가 보상받지 못하고, 목표가 매주 달라져 UI에 미리 보여주기 어렵다.

- 기준 5: 1주 통과율은 이전 기록대로 지수 변동성이 원인(ROUND_TARGETS·드리프트로는 안 됨). 8주 하락과 allCards 부진은 봇이 유물을 무작위로 고르는 탓이 크므로, 먼저 봇이 전략에 맞는 유물을 고르게 한 뒤 다시 재는 것을 권장. 수치로 맞춘다면 `RELIC_RARITY_WEIGHTS` 일반 30 → 20 (쓸모 적은 일반 유물 비중↓)

## 변경 기록: 갭 움직임 + 미수 파산

문제: 1,600판 중 파산 0번. 가격이 부드럽게 움직여 반대매매가 항상 증거금률 25% 근처에서 체결됐고, 파산 엔딩(영끌 실패·숏 스퀴즈·반대매매)이 나오지 않았다.

### 바꾼 것

- **갭** (`rollGaps`, 매 틱 종목 가격 갱신 직후): 종목마다 틱당 확률로 가격이 ±크기만큼 한 번에 튄다. 상승 갭과 하락 갭이 반반(`GAP_UP_SHARE`).
  - 위험도 = volatility + |beta| × `GAP_BETA_WEIGHT`(0.01)
  - 틱당 확률 = 위험도 × `GAP_CHANCE_PER_RISK`(0.035) × `GAP_STATE_MULT` (약세장 ×2, 변동성 장세 ×2.5)
  - 크기 = 위험도 × `GAP_SIZE_PER_RISK`(6) × (1 + 난수), 상한 `GAP_SIZE_MAX` 90%
  - 실측 (평상시 기준 하루 확률 / 평균 크기): 밈코인 10.5% / 90% · 초전도체 7.3% / 90% · 대장코인 4.5% / 82% · 반도체 1.4% / 27% · 곱버스 1.2% / 27% · 지수 인버스 0.7% / 13% · 국밥제약 0.6% / 13%
- 반대매매는 갭 이후 가격으로 체결된다. 포지션 순자산이 0 아래면 청산 금액이 음수(미수)가 된다.
- **미수 파산**: 미수 체결 뒤 현금이 `MISU_CASH_FLOOR`(0) 미만이면 `run.misuDefault` → 파산. 순자산 합계로만 파산을 판정하면 파산이 불가능하다. 봇의 총 노출액은 순자산의 약 1.0~1.3배(p99 1.24배)이고, 반대매매 한 번의 손실은 순자산의 최대 18%였다. 엔딩 분류는 기존 `classifyEnd` 그대로다.
- 1x 롱은 반대매매 대상이 아니므로 갭으로 파산하지 않는다.
- UI:
  - 토스트·뉴스 배너에 "밈코인 갭하락 −90%!"를 띄운다.
  - 차트의 갭 캔들에 금색 테두리와 `GAP` 라벨을 단다.
  - 시세판에는 최근 4캔들 동안 `GAP▼/▲` 태그를 붙인다.
  - 반대매매 미수 알림을 띄우고, 파산 사유 문구에 "미수 발생 — 계좌 동결"을 넣는다.

  - 아무것도 못 샀으면 팩을 산다.

## 변경 기록: 대차 이자 분리 + 인버스 ETF 녹음 (하락 베팅 역할 분담)

문제: 공매도는 노출액 전체에 신용이자와 같은 하루 0.4%(`DAILY_INTEREST`)가 붙고, 인버스 ETF는 이자가 없다. 지수 하락에 걸 때 공매도를 쓸 이유가 없어 보였다.

측정해 보니 원인은 이자보다 두 가지였다.
1. **종목 공통 상승 드리프트.** `STOCK_DRIFT`가 모든 종목에 하루 약 +1.2%로 붙는다. 이자 0.4%의 3배라서, 공매도를 며칠 들고 가면 이 드리프트로 녹는다.
2. **인버스 ETF가 녹지 않았다.** 평소 5일 보유해도 지수 인버스 평균 +3.2%, 곱버스 +2.0%였다. 종목 드리프트가 지수 하락 효과보다 컸다.

### 바꾼 것

- `SHORT_BORROW_RATE` = **0.2%/일**을 `DAILY_INTEREST`(신용·마통 0.4%)와 분리했다. 대차 이자는 빌린 주식 노출액 전체에 붙으므로, 2x 공매도의 원금 대비 하루 비용이 2x 신용 매수와 같아진다. 레버리지 방향만 다르고 비용은 같다.
  - 이자 계산은 `dailyInterest()`로 모았다. 캐피탈 VVIP는 신용·대차 둘 다 할인하고, 공매도 전문가는 대차만 면제한다.
  - 공매도 카드 설명에 "대차 이자 매일 0.2%"를 적었다.
- `INVERSE_DECAY` = 틱당 0.0008을 추가했다. 음(−) 베타 종목의 기대 수익에서 빼서 "장기 보유 시 녹는" 성질을 실제로 만들었다.
- 역할 분담:
  - 인버스 ETF: 이자 없음, 반대매매 없음(1x), 오래 들면 녹는다 → **안전한 하락 베팅**

### 해석과 남은 점

- **위험 쪽은 드러난다.** 공매도 봇은 반대매매 4배, 숏 스퀴즈 파산 1.6%(인버스 봇 0%), 4주 생존이 9%p 낮다.

  - (a) 숏 포지션엔 종목 드리프트를 반만 적용 ("공매도 대기 물량")
  - (b) 매파 발언 약세장에서 고베타 종목 하락폭 확대
  - (c) 공매도 카드에 "장 마감 때 수익 중이면 자동 환매" 옵션

## 변경 기록: 장세별 종목 움직임 +25% (목표 0% / 5% / 10% 인상 비교)

요청: 하락장·상승장·횡보장에서 종목 움직임을 이전보다 25% 크게 만들고, 주간 목표를 0% / 5% / 10% 올렸을 때 봇 클리어율을 보고 가장 밸런스가 맞는 설정을 고른다.

### 바꾼 것

- `STOCK_MOVE_MULT = { NORMAL:1.25, BULL:1.25, BEAR:1.25, VOLATILE:1 }`: 종목 한 틱 움직임에 곱한다.
  - 곱하는 부분: 지수 전달분 + 고유 변동 + 캔들 꼬리.
  - 변동성 장세는 이미 2.8배로 요동치므로 그대로 둔다.
  - 기대 수익(`STOCK_DRIFT`·인버스 녹음·작전 드리프트)과 갭은 건드리지 않는다.
- 목표 인상은 `ROUND_TARGETS` × 1.00 / 1.05 / 1.10을 비교했다 (`--targets`).
  - +5%: 11,340 → … → 57,440
  - +10%: 11,880 → … → 60,170

### 선택: 움직임 +25%, 목표 인상 0% (ROUND_TARGETS 그대로)

- 변동이 커지면 목표선을 넘을 확률이 올라가 클리어율이 전반적으로 +2~3%p 오른다.
- 목표를 5% 올리면 1주 목표가 +8%에서 +13.4%로 뛰어 1주 통과가 6~9%p 떨어진다 (stocksOnly 46.3 → 40.2%). 10%는 더 심하다.
- 목표 0%가 이전에 세운 기준에 가장 가깝다:
  - stocksOnly 8주 15~20%: 12.3%로 가장 가깝다.
  - nothing ≤ 10%: 다른 시드 9.6%로 오차 범위다.
  - 파산율 목표: allCards 3~10%, yolo 15~30%를 그대로 유지한다.
- 목표를 올리면 봇이 빨리 탈락해 파산할 기회 자체가 줄어서 파산율 목표에서 벗어난다. +2%도 마찬가지다.
- 이전과 난이도를 똑같이 맞추고 싶으면 +2%(1주·4주 통과가 before와 거의 같음)가 대안이다.
