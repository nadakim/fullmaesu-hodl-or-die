# 효과음 덮어쓰기 (assets/sfx)

- **파일명 = SFX 이름** (`docs/audio.js` 상단 표의 이름). 예: `coinDrop.ogg`, `crashDown.ogg`.
  비명은 `crowdScream.ogg` 또는 `scream.ogg` (둘 다 받는다).
- **권장 형식: ogg** (mp3·wav도 됨 — 브라우저가 디코딩할 수 있으면 된다).
- 파일을 넣은 뒤 **`files.js`의 `SFX_FILES` 목록에 파일 이름을 적는다.** 목록에 있는 파일만 읽는다
  (브라우저는 없는 파일을 찾아보기만 해도 콘솔에 404 에러를 남기기 때문).
- 파일이 없거나 읽기·디코딩에 실패하면 조용히 합성음으로 돌아간다. 볼륨·사운드 끄기·컴프레서는 합성음과 같다.
- **음높이는 코드가 정한다.** 파일은 한 음(기본 높이)만 녹음하면 된다. 코드가 `Sound.play(이름, {pitch})`의 pitch를
  `playbackRate`로 바꿔서 콤보·정산 단계마다 5음계로 올린다 (재생 길이도 그만큼 짧아진다).
- **라이선스 확인 필수 (CC0 권장).** 스팀 배포 빌드에 들어가므로 출처와 라이선스를 이 파일 아래에 적어 둔다.

| 파일 | 출처 | 라이선스 |
|---|---|---|
| (없음) | | |

## 준비된 이름 — 콤보·정산 (S8-34)

아래 파일을 넣으면 합성음 대신 그 파일이 울린다. 만드는 곳 예: [sfxr.me](https://sfxr.me)(직접 생성 = 저작권 없음), [Kenney](https://kenney.nl/assets?q=audio)(CC0).

| 파일 이름 | 언제 | 음높이 | 권장 길이 |
|---|---|---|---|
| `coin.ogg` | 동전 한 닢. 있으면 `coinDrop`(정산 동전·수익 매도)이 이 파일을 여러 번, 한 닢마다 반음씩 위로 재생 | 코드 (반음씩) | 0.1~0.2초 |
| `billFlip.ogg` | 지폐 넘기기 (정산금 카운트업·찌라시 적중) | 코드 (카운트업 단계) | 0.2초 |
| `cashRegister.ogg` | 금전등록기 "철컹" (정산금이 순자산에 들어갈 때) | 그대로 | 0.5초 |
| `jackpot.ogg` | 수익 콤보 12+ JACKPOT | 그대로 | 1~1.5초 |
| `multSlam.ogg` | 수익 콤보 단계 오름 (3·5·8) | 코드 (단계마다 +2반음) | 0.5초 |
| `comboUp.ogg` | 수익 콤보 +1 | 코드 (5음계 한 칸씩, 2옥타브 넘으면 감아 올림) | 0.15초 |
| `comboBreak.ogg` | 수익 콤보 끊김 ('최대 ×N') | 코드 | 0.4초 |
| `settleThud.ogg` | 장 마감 정산 끝 "둥" | 그대로 | 0.5초 |
| `heartbeat.ogg` | 반대매매 위험 심장 박동 (쿵-쿵 한 번) | 그대로 (간격은 코드) | 0.35초 |
| `shopPad.ogg` | 암시장 입장 몽환 패드 | 그대로 | 3~5초 |

파일을 넣은 뒤 `files.js`의 `SFX_FILES`에 이름을 적고, 아래 출처 표에 한 줄 추가한다.
