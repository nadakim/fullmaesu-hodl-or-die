## 0. 한 줄 결론

- **1주차 첫 5분(1~2일차)에 새로 마주치는 개념이 12개**(목표 4개 이하). 1주차를 끝내면(보상·암시장까지) 8개가 더 붙는다.
- 용어 설명은 대부분 **호버 툴팁(`title=`)과 ≡ 메뉴 깊숙한 용어집**에 있고, '?' 클릭 패널은 없다. 화면에 처음부터 보이는 쉬운 설명은 거의 없다.
- 첫 행동 안내('카드를 눌러 종목을 산다')는 **오른쪽 작은 회색 한 줄**뿐이고, 가장 크고 밝은 것은 `▶ 장 시작` 버튼이다. 그대로 누르면 1주차는 **매수 0회로 끝나 게임오버('관망의 신')**가 된다(이 재현은 §5).
- 실패 시 원인은 **한 줄로 알려 준다**(16개 엔딩 중 승리 제외 15개 전부). **'다음엔 이렇게 해보세요' 힌트는 0개**다.

## 알려진 한계 (모르는 것)

- **사람의 이해 시간·오해는 측정하지 못했다.** 스크립트가 즉시 클릭해서 1일차가 약 40초에 끝났다(실제 첫 사람은 이보다 훨씬 오래 읽는다). '막히는 지점'은 화면 구성에서 추론한 것이지 사용자 테스트 결과가 아니다.
- 호버 툴팁 내용은 스크린샷에 안 찍힌다. 개수(`title` 속성, 화면당 약 30~64개)만 셌다.
- 청산 화면은 1주차에 레버리지가 잠겨 있어 **재현하지 못했다**(`game-over-liquidation`은 청산 화면이 아니라 배경 화면이 측정됨 → 순위에서 제외). 청산 문구는 코드로만 확인했다.
- `bigNumbers`(큰 숫자 수) 지표는 신뢰할 수 없다(어느 화면이든 9 안팎, 코스트 배지 등이 섞임). 4조(큰 숫자 3개 이내)는 스크린샷으로 눈으로 판단했다.
- 창(오버레이)이 떠 있으면 뒤 화면의 글자도 DOM에 남는다 → 창 상태는 '창만' 수치(`overlayChars` 등)를 따로 쓴다. `chart-zoom`·`menu`는 창이 아니라 뒤 화면 포함 수치다.
- 모바일 레이아웃·사운드·시장 지도 타일 색 표시는 이번에 보지 않았다.

### 온보딩 로직이 지금 하는 점진 공개 (확인한 범위)

- `ONBOARDING_ON = true`: 시스템 8개(signals·tips·news 2주, short·leverage·shopTools 3주, sector·fss 4주)를 주차에 맞춰 열고, 한 번 열면 영구(`SYSTEM_UNLOCK_WEEK`). 잠긴 시스템의 카드·유물·보스는 후보에서 빠지고, 시작 덱의 잠긴 카드는 `run.heldCards`로 보관했다가 해금 주에 덱에 넣는다.
- `ONBOARDING_STARTER_SUBS = { stk_inv: 'stk_ev' }`: 시작 덱의 인버스 카드를 1주차에 전기차모터스 카드로 대체.
- 결과적 1주차 손패: 종목 카드 8장(반도체전자 ×2·국밥제약·대장코인·초전도체·밈코인·전기차모터스·치킨게임즈) + 손절 예약·익절 예약 = 10장. (스크린샷 `docs/ux/first3min/03-W1D1-premarket.png`)
- 해금 소개 화면은 3줄 이내(`UNLOCK_INTRO`)이고 설정(`unlockTips`)으로 끌 수 있다.
- **점진 공개가 닿지 않는 곳**(원자료 `week1/*.json` 근거):
  1. 1주차 보상 화면에 `✦ 카드 강화`·`✂ 카드 제거` 버튼이 보인다(암시장 제거는 3주 해금인데).
  2. 1주차 결산·암시장에 **다음 주 보스 예고**('개미 털기 — 갭 확률 ×2, 시그널 적중률 −15%p')가 나온다. 갭·시그널은 2주차 이후 해금/설명되는 개념이다.
  3. 1주차 첫 화면부터 비자금·유물 칸·정산 ×1.00·덱/버림/소멸·목록|지도 토글이 전부 보인다(`week1/play-premarket.png`). 시스템 플래그로 가려지지 않는다.
  4. 종목 시세는 1주차에도 9종목 전부(안정 3·성장·테마 4·코인·투기 2).
  5. 소개창(`UNLOCK_INTRO`)은 시스템 8개에만 있고, **1주차 기본 개념(정산·평단·행동력 등)을 소개하는 창은 없다**.
