# JUICE BIBLE — 도파민 설계 원칙

> 모든 연출·사운드 작업 전에 읽는다. MASTER_PLAN S6·S8의 기준 문서.

## 1. 네 가지 원리

1. **예고 → 공개 → 보상.** 점수를 한 번에 띄우지 않는다. 칩이 더해지고 배수가 곱해지는 과정을 보여준 **뒤에** 폭발한다. 기대가 쌓이는 시간이 쾌감의 절반.
2. **올라가는 음높이.** 연쇄될 때마다 한 칸씩 높아진다 → "다음은 더 높겠지" 예측이 긴장을 만든다.
3. **자기 기준 대비 크기.** 세기는 절대 금액이 아니라 **이번 판 최고 정산 대비 비율**로 정한다. 무한 모드에서도 매번 새롭게.
4. **강약.** 대부분은 가볍고 빠르게, 가끔 크게 ("10번 중 1번"). 모든 게 터지면 10분 만에 피로해진다.

> 연출은 재미를 키울 뿐 만들지 못한다. 불타는 숫자는 **플레이어가 짠 조합의 결과**일 때만 쾌감이 된다.

## 2. 하루 도파민 지도

### 장전 — 기대감 쌓기
| 순간 | 연출 | 소리 |
|---|---|---|
| 아침 드로우 | 카드 부채꼴 촤라락, 희귀 이상 뒤집힐 때 반짝 | 카드 넘김 연타, 희귀엔 종소리 |
| 카드 사용 | 날아가 꽂히며 "탁" | 종류별 음색, 연속 사용 시 음높이 ↑ |
| 예상 정산 미리보기 | "오늘 예상 배수 ×24"가 카드 쓸 때마다 튀며 커짐 | 배수 ↑마다 "딩" 한 칸 위로 |

### 장 시작 — 긴장
화면 살짝 어두워짐 → 3·2·1 + 드럼 롤 → "장 시작!" 벨 + 번쩍.

### 장중 — 몸으로 느끼는 시장
| 상황 | 연출 | 소리 |
|---|---|---|
| 보유 종목 상승 | 포지션 행 가장자리 초록 불꽃, 연속 상승할수록 커짐 | 틱 음높이가 주가를 따라감 |
| 신고가 | 행 금색 번쩍, 불꽃 활활 | 짧은 상승음 |
| 반대매매 위험 | 가장자리 붉은 맥동 + BGM이 점점 답답해짐(위험 로우패스, 암시장과 따로) | 심장 박동 저음, 기준에 가까울수록 빨라짐 |
| 급등 로켓 | 보유 종목이 한 틱 +5%↑·유리한 갭: 마지막 캔들 윗꼬리 끝에서 초록·금색 불꽃이 위로 + 차트 가장자리 만화 속도선 0.4초 (미보유는 차트에 보일 때만 작게) | 상승 스윕 |
| 수익 콤보 단계 오름 (c3↑) | 화면 중앙 "COMBO ×N" 도장 → 줄어들며 콤보 표시 자리로 날아감 (단계당 한 번) | 쾅 |
| JACKPOT (콤보 12) | 도장 + 돈비 | BGM에 합창 패드 + 금관 펄스 레이어 (끊길 때까지, 끊기면 2초에 걸쳐 빠짐) |
| 마감 임박 (마지막 3틱) | 가장자리가 점점 어두워지고 틱 표시(DAY·캔들 n/N)가 빨갛게 깜빡 — 게임 속도는 그대로 | 드럼 롤이 틱마다 촘촘해짐 |
| 수익 매도 | 동전·지폐가 곡선을 그리며 순자산 상자로 (전량 매도는 포지션별 시간차), 도착마다 순자산 숫자 맥박. 손실 매도는 숫자만 | 도착마다 "차링" (최대 12번, 5음계로 위로) |
| 간신히 생존 (위험 → 안전, 반대매매 없이) | 청록 번쩍 + "간신히 생존!" 도장, 심장 박동 멈춤 (같은 포지션 하루 1번) | BGM 로우패스가 확 열리며 맑은 차임 |

### 장 마감 정산 — 메인 이벤트 ⭐
1. 장 마감 종 → 정산 무대, BGM 잦아듦
2. 포지션 하나씩 입장, 기본 수익이 칩처럼 튀어나옴
3. 유물이 **왼쪽부터 차례로** 발동: 더하기 = 경쾌한 "딩" / 곱하기 = "슈욱—펑!" + 약한 흔들림 / 음높이 계속 상승
4. **배수 불타기**

| 누적 배수 | 숫자 | 화면 |
|---|---|---|
| ×10 미만 | 흰색 | 조용 |
| ×10+ | 주황 불꽃 | 약한 흔들림 |
| ×100+ | 파란 불꽃 | 불씨 파티클 |
| ×1,000+ | 보라 불꽃, 숫자 떨림 | 가장자리까지 불길 |
| ×10,000+ | 화면 전체가 불탐 | 최대 흔들림 + 히트스톱 |

   - 배수가 구간(×10·×100·×1,000·×10,000)을 넘는 순간 한 옥타브 올려치는 스윕 + 아르페지오(구간이 높을수록 길게, 음높이는 같은 5음계).
   - 곱하기 단계마다 히트스톱(무대 시간도 같이 멈춘다): 작은 곱은 짧게 + 약한 흔들림 / ×10 이상은 중간 + 테두리 금색 번쩍 /
     **이번 판 최고 정산을 갱신하는 단계만** 가장 길게 + 화면 암전 한 프레임 → 저음 "쿵" + 전체 폭발 (하루 한 번).
   - 금액이 한국 단위(억·조·경…)를 넘으면 새 단위 글자가 1.5배로 튀며 "쿵". 이번 판 처음 닿은 단위면 "첫 1조 돌파!" 도장 (주간 결산 체인 카운트업도 같다).
5. (5%) 크리티컬: 세 칸 릴이 돌다가 "7 7 7"로 한 칸씩 멈춤 (멈추기 직전 0.1초 정지, 멈출 때마다 틱, 마지막에 잭팟음) + 빨간 "CRITICAL ×n" 도장
6. 최종 카운트업 — 동전 소리가 점점 빨라짐, 금액이 클수록 길고 세게
7. 동전·지폐 폭포가 순자산으로 → 순자산 "쾅" → **저음 "둥"** 마침표

**주인공 배수 (juice-stage)**: 상자 중앙에 누적 배수를 크게(`--fs-p4` 40) 띄우고, 값이 바뀔 때마다 log10(배수)에 비례해 커졌다 내려앉는다(팝). 티어(×10·100·1,000·10,000)가 오를수록 뒤의 불꽃이 커지고 색이 변한다(빨강 → 주황 → 보라/빨강 → 흰색 끝). 정산 무대가 열려 있는 동안 흔들림은 `.cabinet`뿐 아니라 정산 상자도 흔든다 (오버레이는 `.cabinet` 밖이라 전엔 안 보였다). 수치는 `JUICE_CONFIG` `hero*`·`boxShakeMul`. 스크린샷 `docs/design/img/stage-juice/`.

속도: 작은 정산은 2배속 자동, 큰 정산만 풀 속도. 클릭 = 빨리 감기, 두 번 = 결과로.

**언제 여나 (stage-every-day)**: 보유 포지션이 있으면 매일 (결산 연출 켬, 주 마지막 날은 주간 결산 체인). 보너스(유물·카드·크리티컬)가 붙은 포지션이 있으면 위의 전체 무대, 없으면 **간이 무대** — 1~2주차에도 매일 "정산" 틀을 보여 줘 배수를 올리고 싶게 만들려고.
- 간이 무대(≈ 1초, `plainStageMs`): 포지션별 "오늘 손익" 칩이 톡톡 → 배수 칸 ×1 고정 → 계산식 `[칩] × [배수 ×1] = [오늘 손익]` → 합계 카운트업 → 순자산 반영 → 낮은 "둥". 불타기·크리티컬 릴·흔들림 없음.
- 배수 칸 옆 힌트 "유물·카드로 배수를 올려보세요" — 판마다 처음 3번(`plainHintRuns`).
- 손실 날: 빨간 숫자 + 내려가는 음, 흔들림 없음. (국밥 정신 같은 환급이 붙으면 전체 무대가 그대로 재생한다.)
- 작은 정산(이번 판 최고 |오늘 손익| 대비 `smallRatio` 미만)은 2배속. 클릭·SPACE 한 번 = 결과로, Enter = 다음 날. 연출 속도 '최소'면 무대 대신 한 줄 알림.

**주간 결산 턱걸이 (목표의 100~103%)**: 결산 체인 끝에 "턱걸이 통과!" 도장 + 긴 한숨 "후우~" + 0.3초 슬로모션.

**가장 센 연출의 빈도** (`node sim/juice-peaks.js` — 봇 판마다 엔진 이벤트를 UI 규칙대로 따라가 센다, 200판):

| 전략 | 정산 무대/판 | 암전/판 | 암전/무대 | 첫 단위 도장/판 | JACKPOT/판 |
|---|---|---|---|---|---|
| levTowerBuild | 9.2 | 3.06 | 33% | 0.63 | 0.34 |
| antFlagBuild | 11.6 | 3.77 | 33% | 0.60 | 0.48 |
| allIn3x | 4.0 | 1.06 | 27% | 0.21 | 0.27 |
| random | 4.1 | 1.04 | 26% | 0.13 | 0.18 |
| nothing | 1.3 | 0.27 | 20% | 0.06 | 0.05 |

곱하기 빌드는 정산이 매일 커지므로 문턱 1(갱신하면 항상)이면 "최고 갱신"이 무대 3번 중 1번꼴 — '10번 중 1번'보다 잦다.
→ **사용자 결정(2026-09-29): `bestBreakFactor` 5** — 직전 최고의 5배를 넘는 단계만 암전. 암전/무대 6~13%(곱하기 빌드 판당 약 1.2번). (2배였다면 14~24%)

### 암시장 — 몽롱함
| 순간 | 연출 | 소리 |
|---|---|---|
| 입장 | 채도↓, 보라 안개 | BGM 로우패스(물속), 몽환 패드 |
| 호버 | 카드 둥실 | 잔향 긴 "띠잉~" |
| 팩 개봉 | 공중에서 흔들리다 터짐, 등급 색 빛기둥 속 카드 하강 | 등급만큼 긴 아르페지오 |
| 신화 | 암전 → 금빛 기둥 → 회전 등장 | 합창 화음 + 깊은 저음 |
| 유물 구매 | 슬롯으로 날아가 "철컥" | 금고 잠김 + 반짝 |

몽롱한 소리 재료: 긴 리버브(ConvolverNode 또는 딜레이 피드백), 살짝 어긋난 두 음(디튠 ±7~12 cent), 느린 LFO 떨림.

### 색 언어 (N4)
- **칩 = 청록 `--cyan`, 배수 = 금색 `--gold`.** 칩은 오늘 손익(base)과 더하기(add), 배수는 합산 배수(+)와 곱 배수(×). 정산 무대·예상 정산 툴팁·카드/유물 툴팁·결산 체인·유물 종류 배지 모두 같다.
- 초록·빨강은 **상승·하락**(최종 금액·손익)에만 쓴다. 줄어드는 칩·배수(국밥 정신 ×0.5 등)도 종류 색 그대로.
- 정산 무대 상단 고정 줄 `[칩] × [배수] = [금액]` — 칩 칸은 청록 테두리, 배수 칸은 금색 테두리. 유물이 발동하면 그 칸이 튀며 숫자가 바뀐다.
- 금액은 슬롯머신처럼 자릿수마다 시간차(`slotDigitGapMs`)로 왼쪽부터 멈추고, 마지막 자리 직전 `preShakeMs` 동안 이번 판 최고 대비 세기에 비례한 흔들림(`preShakePx`)이 먼저 온다 — 흔들림의 크기가 곧 정보.

## 3. 소리 공통 규칙
- 음높이는 **장조 5음계(도·레·미·솔·라)** 로만 오른다 → 어떻게 겹쳐도 불협화음 없음. 2옥타브 넘으면 셰퍼드 톤처럼 한 옥타브 내리고 음색을 밝게.
- 큰 소리엔 BGM 덕킹.
- 정산 끝엔 항상 저음 "둥".
- 고음 연타는 높은 단계일수록 로우패스를 살짝 걸어 귀를 보호.
- 파일(`docs/assets/sfx/<이름>.ogg`)이 있으면 파일 우선, 음높이는 `playbackRate`.

## 4. "놀랄 만큼 쉽게"
- 예상 정산 미리보기: 복잡한 곱셈을 숫자 하나로.
- 쓸 수 있고 배수를 올려주는 카드는 은은하게 빛남.
- 첫 판 첫 주는 좋은 카드·유물 확률 상향 → 첫날부터 불타는 정산을 한 번은 본다.

## 5. 필수 안전장치
- 모든 연출 스킵 가능, 연출 속도 설정(보통·빠름·최소) 준수.
- '화면 흔들림' 끔 / `prefers-reduced-motion` → 흔들림·번쩍임·글리치 없음, 숫자·소리는 유지.
- 동시 파티클 150개 제한, 저사양(사지방 PC·스팀덱)에서 프레임 확인.
- 모든 수치는 `JUICE_CONFIG` 한 곳 → `?tuner=1` 패널에서 사람이 직접 조정 (Claude는 소리를 들을 수 없으므로 "느낌" 조정은 사용자 몫).
- 흔들림 끔·동작 줄이기면 번쩍임·암전·속도선·마감 어둠·슬로모션이 없다 (UI `motionOK()` + `body.no-motion` CSS). 숫자·소리·도장은 남는다.
- 도장(`Fx.stamp`)은 같은 문구만 0.25초 안에 한 번 — 다른 문구는 겹쳐도 막지 않는다 (예: 신고가와 간신히 생존이 같은 틱).
