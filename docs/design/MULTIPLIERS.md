## 크리티컬 정산 (7)

- 수익 포지션을 정산할 때마다 `CRIT_CHANCE` 5% 확률로 발동한다. `CRIT_TABLE`에서 ×2 70% / ×3 25% / ×5 5%를 뽑는다.
- 판정은 `settleDay` 안의 `rollCrit()`이 `rand()`로 한다. 이벤트는 `emit('settleCrit')`.
- 확률은 정산 칩 툴팁과 도감 맨 위에 그대로 나온다 (`critOddsText`).

## 정산 순서

1. 유물을 칸 순서대로 적용한다 (복사 유물 포함).
2. 카드 배수 `p.todayX` (몰빵·모 아니면 도)
3. 선물 만기일 `run.week.futures`
4. 무량대수
5. 크리티컬
6. 타임 루프 (정산을 한 번 더)

2~6은 수익(base > 0)일 때만 적용된다.
