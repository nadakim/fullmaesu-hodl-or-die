# 온보딩 — 시스템 단계 해금

> 첫 판 첫 주에 캔들·롱숏·담보비율·반대매매·행동력·금감원·섹터·비자금·리포트·찌라시 적중률을 한꺼번에 보여 주면
> 주식을 모르는 해외 플레이어·스트리머 첫 방송에서 이탈한다. **"주식 카드를 사고 → 장 마감 정산에서 번다"** 는 핵심 루프만 먼저,
> 나머지는 주차를 넘길 때마다 하나씩 연다.

## 결정 사항 (사용자, 2026-09-29)

| # | 결정 |
|---|---|
| 1 | 해금 순서 = 초안대로 (아래 표) |
| 2 | **해금은 영구** — 어느 판에서든 그 주차에 처음 도달하면 열리고, 다음 판부터는 1주차부터 열려 있다. 소개 창도 다시 안 뜬다 |
| 3 | 첫 주 "배수 보장"(시작 유물 고정·첫 정산 크리티컬 확정 등)은 **실제 게임에 넣지 않는다** — 나중에 만들 튜토리얼에서만 |
| 4 | 그 주에 아직 잠긴 시스템을 겨냥한 보스는 **그 주 후보에서 뺀다** (온보딩 판에서만) |
| 5 | 시작 덱의 잠긴 카드는 빼 두었다가 해금되는 주에 덱에 넣는다 (인버스·곱버스 자리는 1주차 동안 롱 종목 전기차모터스·치킨게임즈로) — 사용자 확인 없이 추천안대로 |

보스 주간(2·4·6·8주)은 기존대로. 잠긴 시스템을 겨냥한 보스만 그 주 후보에서 빠진다 (예: 2주차엔 공매도 금지·빅스텝·증거금 상향·금감원 단속이 안 나온다).

## 규칙 (엔진 `docs/engine.js`)

- 판정 하나: `sysOpenAt(sys, round)` = `!ONBOARDING_ON` 또는 `SYSTEM_UNLOCK_WEEK[sys] <= max(round, run.unlockBase)`.
  `sysOpen(sys)`는 지금 기준 — 보상·암시장 단계는 **다음 주**에 쓸 것이라 `run.round + 1`로 본다(`offerRound`).
- `run.unlockBase` = 판 시작 때 넘겨받은 "지금까지 도달한 최고 주차" (`startNewRun({unlockWeek})`). UI는 localStorage `hodl.unlockWeek`(주 시작 `roundStart`마다 갱신). 시뮬레이터는 넘기지 않으므로 **매 판 처음 하는 플레이어**.
- 막는 곳 (봇도 똑같이 못 한다):
  - 카드 사용 `checkPlay` → `'sysLocked'`
  - 후보 `cardAllowed`(결산 보상·리포트 칸·팩·낱장·변환) · `rollRelics`(결산 유물·암시장 유물)
  - 찌라시 `tipChance()` = 0 (판정 난수는 그대로 소비 — 세력 매집 찌라시도 없음)
  - 암시장 `buyPack('research')`·`shopRemoveCard`·`shopService` → `'sysLocked'`
  - 보스 `rollBossPlan` (그 주에 잠긴 시스템 보스 제외 — 플래그 끔이면 전과 같은 추첨)
- 시작 덱: 잠긴 카드는 `run.heldCards`로 빼 두고 `ONBOARDING_STARTER_SUBS`로 대체 → 새 주 `unlockSystemsForRound`가 열린 카드를 덱에 넣고 `emit('systemUnlocked', {round, systems, cards})` (그 판에서 처음 여는 주에만 — `round > unlockBase`).
- 시그널·뉴스·갭 등 시장 계산은 잠겨도 그대로 돈다 (난수 흐름 유지) — 화면에서만 숨긴다.
- **`ONBOARDING_ON = false`면 도입 전과 완전히 같은 판** (sim/runner.js 결과 JSON 동일 확인).

## 화면 (`docs/demo`)

- `renderLocks()`가 `body.lock-<시스템>` → CSS로 숨김 (시그널 칩·뉴스 줄·장세 뱃지·메뉴 항목·인버스/작전주 시세 줄·금감원 게이지·심지 안내·빌린 돈/이자 툴팁 줄·섹터 뱃지). 암시장 리서치 팩·카드 제거·덱 조작은 그리지 않는다.
- 소개 창 `UNLOCK_INTRO[시스템]` — 한 화면 3줄 이내, 커뮤니티 밈 톤(금지 소재 규칙 그대로). 한 주에 여러 개면 차례로 '▶ 다음'. 보스 경보·다른 창이 먼저 끝난 뒤(`whenFxIdle`). 덱에 들어온 카드는 알림 한 줄.
- 설정 '해금 소개'(`settings.unlockTips`) 끄면 창 없이 알림만. 이어하기는 이벤트가 다시 안 나서 반복 없음.
- 거절 문구 `REJECT_TEXT.sysLocked`·`SHOP_REJECT_TEXT.sysLocked`. 카드 설명 문구는 고치지 않았다.

- 1주차 탈락률: 대부분 전략 −2~−7%p. 잠긴 동안 찌라시 설거지(TIP_VICTIM 168 → 30)·반대매매(MARGIN_CALL 155 → 38)가 줄어든 몫.
- 클리어율: `nothing` 빼고 전 전략 +0.4~+3.8%p (반대매매·찌라시 손실이 1~2주차에 없고, 2주차 보스가 순한 쪽으로).
- `nothing`(카드 0장) 1주차 100% 탈락: 지금까지 1주차 통과는 찌라시 B(안전 선택) 보상 덕이었다. 찌라시가 2주차부터라 `nothing`은 0% — "nothing은 0%에 가깝게" 목표에 맞는다.
- `inverseHedge`는 1주차 탈락 +3.8%p (인버스가 3주차부터라 1~2주차는 롱만) — 대신 2주차 탈락 −12%p.
- 첫 판 기준 시뮬이다. 해금이 영구라 두 번째 판부터는 도달한 주차까지 처음부터 열려 도입 전 판에 가까워진다.

## 점검

- 테스트 `tools/tests/onboarding.cjs`: 1주차 잠긴 UI 숨김·잠긴 카드 차단·후보 제외·암시장 → 2주차 소개 3장(한 장 3줄 이내)·저장 → 이어하기 반복 없음 → 3주차 소개·시작 카드 복귀 → 새 판은 도달 주차까지 열림 → 설정 끔 = 창 없음 → 플래그 끔 = 전부 보임.
- 다른 테스트는 1주차부터 공매도·신용 등을 쓰므로 `localStorage.hodl.unlockWeek = '8'`로 시작한다 (tools/tests/README.md).
