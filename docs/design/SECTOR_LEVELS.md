# 섹터 레벨 (N3)

> MASTER_PLAN §9 N3. 2026-09-28 도입. 발라트로가 행성 카드로 족보를 레벨업하듯, **섹터를 레벨업해서 "이번 판은 코인에 올인" 같은 방향**을 만든다.
> 참고: SETTLEMENT.md(정산 단계), DECKBUILDING.md(태그 가중·강화), MULTIPLIERS.md(섹터 풀세트 = 섹터 수만큼 ×, 반대 방향의 "분산" 빌드).

## 규칙

- 상태 `run.sectorLevel[섹터 이름]` = 1부터 (`newSectorLevels`, 섹터 목록 = CONFIG `SECTORS` 11개 = `STOCKS`의 sector).
- **정산**: 그 섹터 포지션이 **수익으로 장 마감**(base > 0)하면 `settleSteps` 맨 앞(보유 칩 다음, 유물보다 먼저)에 두 단계를 넣는다.
  - `add` 칩 = 포지션 원금 × `SECTOR_LEVEL_CHIP_PCT`(2%) × (레벨 − 1)
  - `mult` 합산 배수 = `SECTOR_LEVEL_MULT`(0.25) × (레벨 − 1)
  - 라벨 `📊 암호화폐 Lv.3`, source `'sector'` (유물이 아니므로 `relicTriggered` 없음). 레벨 1이면 아무것도 없다. 손실 마감엔 없다.
  - 맨 앞에 두는 이유: 칩(더하기)과 합산 배수는 앞에 있을수록 뒤의 곱 배수(유물 ×)에 곱해진다 → 섹터 레벨과 곱하기 유물이 서로 키운다.
- **미리보기** `previewSettlement`: 포지션 배수 = 유물 배수 × (1 + 섹터 칩 ÷ 유리하게 1% 움직인 손익). 레벨 1이면 전과 같다.
- **획득**: 카드 종류 `report`(리포트) 11장 — 섹터마다 1장, 행동력 `SECTOR_REPORT_AP`(**0**, 조정안 3), 고급(uncommon), 사용 후 소멸. 쓰면 `raiseSectorLevel(섹터, 1)` → `emit('sectorLevelUp')`. 강화판(+) = 레벨 +1 + 카드 `SECTOR_REPORT_UP_DRAW`(1)장 뽑기.
  - **소멸은 그 주만**이다 (다음 주 `buildWeekPiles`가 덱에서 다시 만든다) → 덱에 넣은 리포트는 **뽑힐 때마다 +1** (발라트로 행성 카드와 달리 반복 레벨업 재료).
  - **결산 카드 보상의 마지막 칸 = 리포트 칸** (`SECTOR_REPORT_SLOTS` 1, 조정안 1 — `rollRewardChoices`): 덱에 없는 리포트 중 최고 레벨 섹터 가중(`pickTagged`)으로 1장. 리포트가 다 덱에 있으면 그 칸은 일반 카드. 화면: 보상 제목 '마지막 칸은 📊 섹터 리포트'.
  - 그 밖에 암시장 낱장·팩(`CARDS` 전체 풀)에도 등장. 새 팩 **📑 리서치 팩**(`RESEARCH_PACK`, 400, 종목 카드 일반 40% · 리포트 고급 60%).
- **보상 가중**: 레벨이 가장 높은 섹터(최고 레벨 2 이상, 동률이면 전부 = `topSectors()`)의 종목 카드·리포트 카드는 같은 등급 안 가중치 +`SECTOR_BIAS`(0.3). 태그 가중(`TAG_BIAS`)과 더한다 (`tagWeight`). 등급 확률은 그대로. 팩 확률 팝업(`packCardOdds`)은 이 가중치를 반영한 확률 + 안내 문구.
- **플래그** `SECTOR_LEVELS_ON`(true): false면 리포트 카드·리서치 팩을 만들지 않고 모든 섹터 레벨 1 → 도입 전과 **같은 판** (시뮬 500판 × 12전략 JSON 동일로 확인).

## 화면

- 카드 종류 '리포트'(안쪽 테두리 `--text`), 들고 있는 섹터의 리포트는 손패에서 빛남(`boostsSettle`).
- 시세판 종목명 옆 `Lv3` 금색 뱃지 (레벨 2부터, 툴팁 = 지금 효과).
- ≡ 메뉴 › 📊 섹터 레벨 (`showSectorLevels`): 섹터·종목·레벨·지금 효과(칩 청록 · 배수 금색)·리포트 카드, 최고 레벨 섹터는 금색 줄 + "보상 +30%".
- 정산 무대: 섹터 칩(청록)·배수(금색)가 유물보다 먼저 재생. 레벨업 알림 + 해당 섹터 시세 행 번쩍.
- 팩 팝업: "같은 등급 안 가중치: 빌드 태그 … +30% · 📊 최고 레벨 섹터 … +30%".

## 시뮬 (500판, `sim/runner.js`)

기존 12전략은 **±1%p 안** (리포트 11장이 고급 보상 풀을 조금 희석). 전후 `sim/results/baseline-before-n3-sector.json` → `after-n3-sector.json`.

새 전략 `sectorAllIn`(암호화폐 리포트 우선 · 신용으로 대장코인만 · 리서치 팩): 클리어 0% (플래그 끔도 0%) — 코인 한 종목·레버리지 롱은 원래 1~2주 안에 무너진다. 판 끝 최고 섹터 레벨 평균 1.9.

- **지금 수치로는 너무 강하지 않다 — 오히려 약하다.** 판 안에서 자연스럽게 모이는 레벨(평균 +0.9)로는 결과가 거의 안 바뀐다. 리포트가 고급 카드 중 하나라 잘 안 나온다.
- 레벨이 쌓이면 효과는 크다: Lv.5를 처음부터 가지면 생존 1주 → 4주, 최고 순자산 중앙 10배. 그래도 클리어가 낮은 건 7~8주차 목표(150억~300억)가 곱하기 유물 없이는 닿지 않기 때문 — 섹터 레벨은 **곱하기 빌드의 앞 칸 칩·배수**로 붙을 때 의미가 있다.

## 조정안 (2026-09-28 사용자 결정: 1의 '보상 리포트 칸' + 3 적용)

1. **리포트를 더 자주**: 결산 카드 보상 3장 중 1장을 "리포트 칸"으로 (발라트로 상점의 행성 카드 칸처럼) / 리서치 팩 400 → 250 / 리포트 등급 고급 → 일반.
2. **레벨 효과 키우기**: `SECTOR_LEVEL_MULT` 0.25 → 0.5, `SECTOR_LEVEL_CHIP_PCT` 2% → 3~5% (위 표 Lv.5 + 5%·0.5 = 생존 5.8주).
3. **리포트 행동력 0** (`SECTOR_REPORT_AP` 1 → 0): 장전 행동력을 매수와 다투지 않게.
4. **섹터 가중 키우기**: `SECTOR_BIAS` 0.3 → 1.0 (최고 섹터 카드가 등급 안에서 2배) — 500판에서 0.3은 무작위 봇 3판만 바꿨다.

추천: 1(보상 리포트 칸) + 3(행동력 0). 효과 수치(2)는 곱하기 빌드와 합쳐 폭주할 수 있어서, 먼저 획득 빈도를 올린 뒤 다시 잰다.
