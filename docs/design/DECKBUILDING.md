### 규칙

- 강화판은 `defUpgrade(id, over)`가 만든 `id+` 카드다. `CARD_BY_ID`에만 있고 `CARDS`(보상·팩·도감 후보)에는 없다. 필드 `base`(원래 id)·`upgraded`.
- 수치는 CONFIG `*_UP` 상수. 효과 함수가 쓰는 플래그는 불린 대신 수치를 담는다 (`p.stopLoss`·`p.takeProfit` = 발동 %, `p.diamond` = 보너스율, `run.week.valueGod` = %, `run.lossGuardToday` = 환급률, `run.circuitToday` = 하락폭).
- 같은 카드인지 볼 때는 `base`로 본다: `inDeck`(덱에 없는 카드만 보상), `cardCost`(주간 효과·유물), 리딩방 확률 `pumpChanceFor`, 시장 카드 확률표 `MARKET_CARD_ODDS['dove+']`.
- 얻는 곳: 주간 보상에서 새 카드 대신 **✦ 카드 강화**(`chooseReward('upgrade', deckIdx)`), 암시장 **리모델링**.

## 빌드 태그 7종 (11)

🔥 레버리지 · 📉 공매도 · 💎 존버 · ⚡ 단타 · 🎰 찌라시 · 🕴 작전 · 🐜 분산 (`TAGS`, `CARD_TAGS`, `RELIC_TAGS`). 카드 발밑·유물 타일에 아이콘, 툴팁에 이름.

- `topTags()` = 덱 + 보유 유물에서 가장 많은 태그(동률이면 전부).
- 카드 보상·팩·낱장 진열·유물 보상·유물 진열은 **등급을 먼저 굴린 뒤(`rollRarity`, 확률 그대로) 등급 안에서** 상위 태그를 가진 후보의 가중치를 `1 + TAG_BIAS`(0.3)로 (`pickTagged`). 팩 확률 팝업(`packCardOdds`)도 같은 값을 보여 준다.

## 덱 순환 (12, D6)

- 전: 매일 손패를 버리고, 매주 덱 전체를 새로 섞음.
- 후: **뽑을 더미가 빌 때만 버린 더미를 섞는다.** 새 주(`buildWeekPiles`)에는 뽑을 더미 순서를 그대로 두고, 덱에서 빠진 카드는 지우고 새로 들어온 카드·강화·변환은 버린 더미에 넣는다. 한 주에 다 못 뽑은 카드가 다음 주에 먼저 나온다.
- 장 마감에 쓰지 않은 손패는 버린다. 예외: `retain: true` 카드는 손패에 남는다 (틀만 있고 아직 쓰는 카드 없음 — S4 곱하기 카드에서 사용 예정).

## 종목 카드 금액 직접 입력 (13)

- 종목 카드를 누르면 금액 창: 슬라이더 · 10/25/50/전액 · 숫자 입력, 투입 원금·노출액·남는 현금·정산 배수 ×a → ×b · 유리하게 1% 움직일 때 손익. Enter = 매수, Esc = 취소.
- 엔진: `playCard(handIdx, targetId, {amount})` → `run.buyAmount` → `stockCost(s)` = 금액 × 영끌 원금 배수. 최소 `STOCK_BUY_MIN`(50만, 미만이면 `'amount'` 거절), 최대 `stockMaxAmount()` = 현금 ÷ 원금 배수. `amount` 없이 부르면 전처럼 기본값 `s.cost` (봇·기존 호출 그대로).
- 미리보기 `hypotheticalBuy(stockId, amount)`.

## 암시장 덱 조작 (10)

카드 제거 목록에서 카드를 고른 뒤: **✦ 리모델링**(강화, 기본 350) · **🔀 변환**(같은 등급의 덱에 없는 다른 카드로, 태그 가중 — 200) · **📑 복제**(한 장 더, 신화 제외 — 450). `shopService(kind, deckIdx)` → `emit('shopServiced')`. 비용 `serviceCost(kind, n)` = 기본 × `SHOP_SERVICE_ESCALATION`(1.5)^이번 주 n번째, 물가 `SHOP_INFLATION.service` 주당 +12%.
