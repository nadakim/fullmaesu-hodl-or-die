# 규칙 파괴형 유물 10종

> 발라트로 조커처럼 **게임 규칙 자체를 바꾸는** 유물. 수치 보정(add·mult·xmult)만으로는 "이게 된다고?" 장면이 안 나온다.
> 원칙: 유물마다 **큰 제약 1개 + 큰 보상 1개**, 단순 +수치 없음. 칸 순서와 얽히는 것 3종(몰아주기·막차 탑승·무소유 투자법), 새 빌드 축 2종(무소유 = 유물 미니멀 · 교주 = 단일 종목 올인).
> 플래그 `RULE_BREAKER_RELICS_ON` — 끄면 `RELICS`에 들어가지 않아 도입 전과 결과 JSON이 같다 (확인함).

## 결정 사항 (사용자, 2026-09-29)

- 10종 그대로 진행.
- 🚂 막차 탑승: 제곱 대신 **m → m^1.5** (`LAST_TRAIN_POW`).
- 🕳️ 무소유 투자법: 빈 칸당 **×1.5**로 시작 (`CASHGANG_PER_EMPTY`, 초안 1.8).
- 등장: 결산 보상·암시장 유물 풀에 기존 등급 가중치 그대로. 온보딩 해금은 기존 시스템에 맞춰 (역지표 = 공매도 3주차, 영끌 대출 = 레버리지 3주차, 확신범 = 찌라시 2주차).

## 위험 표시

- **무한 루프 (Open Q1 형태)**: 🙏 풀매수 교주 — 행동력 0 종목 카드 + 개미 군단 총공격(쓸 때마다 드로우) + 얇은 덱이면 연쇄 매수. 매수마다 현금이 들어 **현금이 떨어지면 끝난다** (무한 아님). 초안에서 뺀 '상폐 수집가(소멸 카드 재순환)'는 드로우 카드와 진짜 무한 루프가 가능해서 제외.
- **새 훅**: 단타 중독(매도 시 정산), 영끌 대출(매수 가능 현금 함수 하나로), 찌라시 확신범(찌라시 효과 변환 + 기대값).
- **폭주**: 막차 탑승(m^1.5 — 무량대수·레버리지 탑과 겹치면 자릿수 폭발), 존버 서약서(×130), 물타기(×64).
- 찌라시 매수 효과(`buy`)는 교주 차단 대상이 아니다 (찌라시가 사 주는 것). 단타 정산은 전량 매도(`closePosition`)만 — 분할 매도(`closePart`)는 제외.

## 연출

- 정산 무대: 규칙 파괴 유물 단계가 발동하면 계산식 줄 아래 `#sfRule`에 "⚠ 규칙 파괴 · (유물 단계 라벨)" — N4 색 언어대로 칩(더하기)은 cyan, 배수(+·×)는 gold (`stageRuleName`).
- 단타 중독 매도 정산: 알림 한 줄 + 배수 칩 + `settleMult` 5음계 + 수익 콤보. 물타기 물·대출 이자·무소유 비자금은 알림.
- 유물 종류 배지: 막차 탑승 = `⤓`(맨 오른쪽 칸 전용), 몰아주기 = `⇄`(복사류).
- 튜너 `?tuner=1`: '유물 장착'(규칙 파괴형이 목록 맨 위) → 바로 장착해 확인.

## 측정 보정 (PR #33 후속, 2026-09-30 — 유물 수치·엔진 규칙은 바꾸지 않음)

PR #33 첫 측정은 ruleBreakerBuild 47.0% → 28.4%였는데, 이 봇이 규칙 파괴 유물을 가진 판의 클리어율은 63~77%였다. 편향 세 가지를 의심했다.
1. **봇 편향**: 10종을 다 집어 칸 6개가 규칙 파괴 유물로 차고, 서로 충돌하는 조합(존버 서약서의 매도 금지 + 단타 중독)도 함께 집는다.
2. **러너 편향**: 러너는 장중 매도를 못 해서 단타 중독은 불리하고, 존버 서약서는 제약이 공짜라 유리하게 잰다.
3. **생존 편향**: '채택한 판'은 유물을 얻을 만큼 오래 산 판이라 원래 클리어율이 높다.

- **아키타입 봇 4종 + scalperBot** (`sim/strategies.js`). 공통 규칙은 셋이다. 자기 빌드의 규칙 파괴 유물만 집는다(`relicFilter`). 원하는 게 없으면 기존 곱하기 유물을 집는다. 칸 순서를 의도대로 둔다(`arrange`).
  - `oathHold`: 존버 서약서 + 물타기 장인 + 성장형. 1x 롱을 사서 팔지 않고, 손실 포지션에 물타기한다.

### 결론

- **보정하면 거의 모든 유물이 '채택하면 손해'로 움직인다.** 첫 측정의 +값 일부는 생존 편향이었다. 예: 몰아주기 +4.2 → −7.2%p, 교주 +6.1 → −3.8%p.
- **💎 존버 서약서만 확실한 플러스**다. 보정 후 +18.3%p / +4.7%p이고, oathHold 봇도 +2~+6%p. '+20%p↑' 표시는 보정하면 사라진다. 첫 측정의 +21.9%p는 생존 편향과 러너 편향(봇이 원래 안 팔아서 제약이 공짜)이 겹친 값이다.
- **⚡ 단타 중독은 편향을 걷어내도 가장 약하다.** 장중 매도 봇(scalperBot)도 −28~−34%p이고, 3주차 보유 판 클리어는 12~13%. 매도 정산은 판당 약 47번 실제로 터진다(평균 배수 큼). 그런데 팔고 나면 다음 장전에 종목 카드가 있어야 다시 산다. 돈이 쉬고 장 마감 보너스도 없어서 목표를 못 따라간다. **러너 편향이 아니라 설계상 약점이다.**
- **🐜 인간 역지표 −20~−34%p · 🚂 막차 탑승 −18~−23%p · 🎰 찌라시 확신범 −12~−16%p · 🏦 영끌 대출 −9~−14%p** (보정 기준). 그중 막차 탑승은 cultFocus 봇에서는 폭주 시드를 만든다(×5.96e+13). 평균은 낮은데 천장은 높은 유물이다.
- 폭주 시드: 시드 1~500에서 9500판 중 11판, 1001~1500에서 3000판 중 13판. 모두 졸업한 판이다. 최대 하루 배수 ×2.24e+19는 ruleBreakerBuild에서 무소유·물타기·몰아주기·막차·확신범·교주·대출이 한꺼번에 겹친 경우다.
