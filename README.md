Retro 2D trading game prototype — HODL or Die

# 풀매수 기원단: HODL or Die
> 주식 시장의 급등락과 도파민을 카드 게임으로 재해석한 레트로 2D 트레이딩 게임.

## 🎮 Project

**풀매수 기원단: HODL or Die**는 주식 시장의 급등과 폭락을 게임 시스템으로 재해석한 2D 게임 프로젝트입니다.

현재는 군복무로 인하여 사이버지식정보방에서 HTML / CSS / JavaScript / Canvas를 활용한 웹 프로토타입을 개발하고 있으며, 이후 Unity + C# 기반의 게임으로 발전시키는 것을 목표로 합니다.

## ✨ Core Features

* 실시간 OHLC 캔들 차트
* 매수 / 매도 시스템
* 현금 및 포지션 관리
* 평가손익 / 확정손익
* 랜덤 시장 변동
* 급등 / 급락 시장 이벤트
* 카드 시스템
* 유물 시스템
* 상점 시스템
* 레트로 픽셀 UI
